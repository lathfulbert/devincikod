🎯 Objectif global

Créer un composant Logging & Monitoring totalement modulaire, extensible, désactivable, et compatible avec le système de modules du Core.

🔥 1. SYSTÈME DE LOGGING – Spécifications
1.1. Caractéristiques principales

Le système doit :

gérer plusieurs canaux de log (single, daily, slack, database, syslog, stderr)

suivre la structure Laravel, mais optimisé pour LathDevinci

implémenter les niveaux PSR-3
(emergency, alert, critical, error, warning, notice, info, debug)

permettre la rotation automatique des fichiers (daily)

utiliser une classe Logger centrale dans Core/Logging/Logger.php

charger la configuration dans config/logging.php

respecter PSR-3 (interface LoggerInterface)

supporter un middleware automatique pour log des requêtes HTTP

supporter un Handler dynamique pour ajouter de nouveaux types de logs

1.2. Modules inclus

Générer le code complet pour :

Logger (implémentation principale)

LogManager (gestion des canaux)

Handlers :

ExceptionHandler (Gestion centralisée des erreurs)

Helpers log() et façade Log::
