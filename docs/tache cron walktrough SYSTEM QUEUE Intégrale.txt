queue:work

php sunu queue:work
# Process from specific queue

3. 
queue:retry
 ✅
Retry failed jobs.

# Retry specific job
php sunu queue:retry 1
# Retry all failed jobs
php sunu queue:retry --all
What it does:

Fetches failed job from failed_jobs table
Re-queues it to the original queue
Deletes from failed jobs table
Resets attempt counter
4. 
queue:flush
 ✅
Clear all jobs from a queue (with confirmation).

# Flush default queue
php sunu queue:flush
# Flush specific queue
php sunu queue:flush emails
Safety: Requires yes confirmation before deletion.

5. 
queue:restart
 ✅
Signal all workers to restart gracefully.

php sunu queue:restart
How it works:

Creates storage/queue/restart signal file
Workers check for this file
When found, workers finish current job and exit
Supervisor/systemd automatically restarts them
Fresh workers start processing

Production Deployment Guide
Method 1: Supervisor (Linux - Recommended)
Install Supervisor:

sudo apt-get install supervisor
Configuration: /etc/supervisor/conf.d/queue-worker.conf

[program:queue-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/app/sunu queue:work default
autostart=true
autorestart=true
stopwaitsecs=60
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/www/app/storage/logs/worker.log
stdout_logfile_maxbytes=10MB
stopasgroup=true
killasgroup=true
Start Workers:

sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start queue-worker:*
Manage Workers:

# View status
sudo supervisorctl status
# Stop workers
sudo supervisorctl stop queue-worker:*
# Restart workers (graceful)
php sunu queue:restart
# Restart workers (force)
sudo supervisorctl restart queue-worker:*
# View logs
tail -f /var/www/app/storage/logs/worker.log
Method 2: systemd (Linux Alternative)
File: /etc/systemd/system/queue-worker.service

[Unit]
Description=Queue Worker
After=network.target
[Service]
Type=simple
User=www-data
WorkingDirectory=/var/www/app
ExecStart=/usr/bin/php /var/www/app/sunu queue:work default
Restart=always
RestartSec=3
[Install]
WantedBy=multi-user.target
Control:

sudo systemctl enable queue-worker
sudo systemctl start queue-worker
sudo systemctl status queue-worker
Method 3: Windows (Development)
Run in terminal:

php sunu queue:work default
Or create batch file start-worker.bat:

@echo off
:loop
php sunu queue:work default --max-jobs=100
timeout /t 5
goto loop
Complete Usage Guide
Creating Jobs
<?php
namespace Modules\Blog\Jobs;
use App\Core\Queue\Job;
class PublishScheduledPostsJob extends Job
{
    protected int $tries = 5;
    protected int $retryAfter = 60; // seconds
    protected int $timeout = 300;   // 5 minutes
    public function handle(): void
    {
        $data = $this->getData();
        $postIds = $data['post_ids'];
        
        foreach ($postIds as $id) {
            // Publish post logic
        }
    }
    public function failed(\Throwable $exception): void
    {
        // Send alert to admin
        error_log("Failed to publish posts: " . $exception->getMessage());
    }
}
Dispatching Jobs
// Immediate
PublishScheduledPostsJob::dispatch([
    'post_ids' => [1, 2, 3],
], 'blog');
// Delayed (in 1 hour)
PublishScheduledPostsJob::dispatchAfter(3600, [
    'post_ids' => [4, 5, 6],
], 'blog');
Configuration
config/queue.php
:

return [
    'driver' => 'database', // 'database', 'redis', 'file'
    
    'connections' => [
        'database' => [
            'table' => 'jobs',
            'failed_table' => 'failed_jobs',
        ],
    ],
    
    'worker' => [
        'sleep' => 3,          // Sleep when no jobs (seconds)
        'max_tries' => 3,      // Default max attempts
        'timeout' => 60,       // Default timeout (seconds)
        'memory_limit' => 128, // Memory limit (MB)
    ],
];

Performance Tips
1. Multiple Workers
Run multiple worker processes for better throughput:

# In Supervisor config
numprocs=4  # Run 4 workers
2. Queue Priority
Use different queues for different priorities:

// High priority
CriticalJob::dispatch($data, 'high');
// Normal priority
NormalJob::dispatch($data, 'default');
// Low priority
CleanupJob::dispatch($data, 'low');
Start workers for each:

php sunu queue:work high &
php sunu queue:work default &
php sunu queue:work low &
3. Memory Management
Workers automatically restart when memory limit is reached. Adjust in config:

'worker' => [
    'memory_limit' => 256, // Increase for heavy jobs
],
4. Job Batching
For bulk operations, batch jobs:

// Instead of 1000 individual jobs
foreach ($users as $user) {
    SendEmailJob::dispatch(['user_id' => $user->id]);
}
// Use one batched job
BatchSendEmailJob::dispatch([
    'user_ids' => $userIds,  
    'chunk_size' => 100,
]);
