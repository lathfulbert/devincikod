🚀 Production Deployment
Queue Workers (Supervisor)
/etc/supervisor/conf.d/queue-worker.conf:

[program:queue-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/app/sunu queue:work default
autostart=true
autorestart=true
stopwaitsecs=60
user=www-data
numprocs=4
redirect_stderr=true
stdout_logfile=/var/www/app/storage/logs/worker.log
Start workers:

sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start queue-worker:*
Cron Scheduler (System Cron)
Add to crontab:

crontab -e
* * * * * cd /var/www/app && php sunu cron:run >> /dev/null 2>&1
Ceci exécute le scheduler chaque minute qui ensuite lance les tâches selon leur expression.

💡 Usage Examples
Creating a Job
<?php
namespace Modules\Reports\Jobs;
use App\Core\Queue\Job;
class GenerateReportJob extends Job
{
    protected int $tries = 3;
    protected int $timeout = 600;
    public function handle(): void
    {
        $reportId = $this->getData()['report_id'];
        // Generate report logic
    }
}
Dispatch:

GenerateReportJob::dispatch(['report_id' => 123]);
Creating a Cron Task
<?php
namespace Modules\Backup\Cron;
use App\Core\Cron\CronTask;
class DatabaseBackupTask extends CronTask
{
    public function expression(): string
    {
        return '0 3 * * *'; // Daily at 3 AM
    }
    public function description(): string
    {
        return 'Backup database';
    }
    public function handle(): void
    {
        // Backup logic
    }
}
Register in Modules/Backup/cron.php:

<?php
return [
    \Modules\Backup\Cron\DatabaseBackupTask::class,
];
📊 Command Reference
Queue
# Start worker
php sunu queue:work default
# Process 10 jobs then stop
php sunu queue:work default --max-jobs=10
# List failed jobs
php sunu queue:failed
# Retry specific job
php sunu queue:retry 5
# Retry all failed
php sunu queue:retry --all
# Clear queue
php sunu queue:flush default
# Restart workers
php sunu queue:restart
Cron
# Run scheduler (for system cron)
php sunu cron:run
# List registered tasks
php sunu cron:list
# Run specific task manually
php sunu cron:run-task "Modules\Admin\Cron\TestCronTask"
# Show statistics (needs cron_tasks table populated)
php sunu cron:stats
🎯 Accepted Cron Expressions
Expression	Meaning
* * * * *	Every minute
0 * * * *	Every hour
0 0 * * *	Daily at midnight
0 0 * * 0	Weekly (Sunday)
0 0 1 * *	Monthly (1st)
0 */6 * * *	Every 6 hours
0-5 * * * *	Minutes 0-5
0,30 * * * *	At :00 and :30
