1) Installation & démarrage

Prérequis: PHP 8+, Composer, un serveur web (Apache/Nginx) ou PHP built-in server.

Étapes rapides :

# dézippez le projet
unzip "sunuframework2 - Copie.zip"
cd "sunuframework2 - Copie"
# installer les dépendances php (si composer.json ajouté)
composer install
# copier .env et adapter
cp .env.example .env
# lancer le serveur pour développement
php -S localhost:8000 -t public

2) Structure du projet

Points clés trouvés dans l'arborescence :

  • /Core — noyau: Application.php, Router, View, ModuleLoader/Manager, Database, ORM, Security (CSRF), I18n, Cache, Middleware.
  • /config — fichiers de configuration (app.php, database.php, etc.).
  • /Modules — modules plug-and-play (architecture modulaire).
  • /templates — vues/templates pour le moteur de templates.
  • /public — point d'entrée web (index.php, assets).
  • composer.json — autoload PSR-4 (namespaces: App\Core, Modules\).

3) Configuration

Le framework charge config/app.php et utilise un .env. Ajustez les valeurs DB et APP à l'intérieur du fichier .env.

// esempio: config/app.php chargé par Application
$this->config->load($this->basePath . '/config/app.php');

4) Routing

Le routeur expose des méthodes pour les verb HTTP : get, post, etc. Il supporte les callbacks et les paires [ControllerClass::class, 'method'].

use App\Core\Routing\Router;

$router = new Router();
$router->get('/', [App\Controllers\HomeController::class, 'index']);
$router->post('/login', [App\Controllers\AuthController::class, 'login']);

// route avec middleware
$router->get('/admin', [AdminController::class,'index'], ['auth','admin']);

Le routeur tente de matcher l'URI et appelle callHandler en injectant les paramètres.

5) Contrôleurs et gestionnaires

Les contrôleurs sont des classes PHP simples placées dans Modules/.../Controllers ou App\Controllers. Exemple minimal :

namespace App\Controllers;

class HomeController {
    public function index() {
        return view('home', ['title' => 'Bienvenue']);
    }
}

6) Vues et Template Engine

La classe App\Core\View\View initialise un moteur de templates. Les templates sont sous /templates. Utilisez view('path.to.view', $data) pour rendre une page.

// render dans un contrôleur
return $this->view->render('pages.home', ['user' => $user]);

7) Modules

Modules sont chargés depuis /Modules par un ModuleLoader/ModuleManager. Pour créer un module :

  1. Créer dossier Modules/MyModule
  2. Ajouter Controllers, Models, Views, et un fichier d'enregistrement (ex: module.json ou une classe Module.php).
  3. Le ModuleLoader scanne le dossier et instancie/registre les routes et services.

8) Base de données & ORM

Le framework contient un composant Database et un ORM basique (QueryBuilder, Relations, Schema). Exemple de connexion :

// dans Application
\App\Core\Database\Database::getInstance()->connect($this->config->get('database', []));

Utilisez le QueryBuilder pour construire des requêtes ou le modèle ORM pour relations (BelongsTo, HasMany...).

9) Sécurité (CSRF, Auth)

CSRF est initialisé par App\Core\Security\CSRF::getInstance(). Les middlewares incluent CSRFMiddleware et un système d'authentification est présent sous Core/Auth.

10) Internationalisation (I18n)

Le dossier Core/I18n contient un Translator, LanguageLoader et un middleware SetLocaleMiddleware. Les traductions sont mises en cache et chargées via un LanguageCache.

11) Cache, Middleware & Services

Cache: interface & implémentations dans Core/Cache. Middleware: placez-les dans Core/Middleware ou Modules/.../Middleware et attachez-les aux routes.

12) Utilitaires & scripts

Un fichier utilitaire check_tables.php est inclus. Des helpers sont chargés depuis config/Support/helpers.php. Adaptez selon vos besoins.

Exemple du QueryBuilder

// Core/Database/QueryBuilder.php
class QueryBuilder {
    protected PDO $pdo;
    protected string $table;
    protected array $wheres = [];

    public function __construct(PDO $pdo, string $table) {
        $this->pdo = $pdo;
        $this->table = $table;
    }

    public function where(string $column, string $operator, mixed $value): static {
        $this->wheres[] = [$column, $operator, $value];
        return this;
    }

    public function get(): array {
        $sql = "SELECT * FROM {$this->table}";

        if (!empty($this->wheres)) {
            $conditions = array_map(fn($w) => "$w[0] $w[1] ?", $this->wheres);
            $sql .= " WHERE " . implode(' AND ', $conditions);
        }

        $stmt = $this->pdo->prepare($sql);
        $values = array_column($this->wheres, 2);
        $stmt->execute($values);

        return $stmt->fetchAll(PDO::FETCH_ASSOC);
    }
}

Intégration Model + QueryBuilder

// Core/Database/Model.php
abstract class Model {
    protected static string $table;
    protected array $fillable = [];

    public static function query(): QueryBuilder {
        global $pdo; // instance PDO
        $instance = new static;
        return new QueryBuilder($pdo, $instance->table);
    }

    public static function all(): array {
        return static::query()->get();
    }

    public static function find($id): array|null {
        $results = static::query()->where('id', '=', $id)->get();
        return $results[0] ?? null;
    }
}
