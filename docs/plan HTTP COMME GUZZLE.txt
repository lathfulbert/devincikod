
HTTP Client System - Implementation Plan
Implement a complete HTTP client for making external API requests, inspired by Laravel's Http facade and Guzzle.

	Architecture
	Http::get
	PendingRequest
	Client::send
	cURL Request
	Response
	json/body/status
	Core Components
	1. Client Class
	File: Core/Http/Client.php

	class Client
	{
		public function send(Request $request): Response
		public function get(string $url, array $query = []): Response
		public function post(string $url, array $data = []): Response
		public function put(string $url, array $data = []): Response
		public function delete(string $url): Response
		public function patch(string $url, array $data = []): Response
	}
2. Response Wrapper
File: Core/Http/Response.php

class Response
{
    public function body(): string
    public function json(): array
    public function status(): int
    public function successful(): bool
    public function failed(): bool
    public function header(string $key): ?string
    public function headers(): array
}
3. PendingRequest (Fluent API)
File: Core/Http/PendingRequest.php

class PendingRequest
{
    public function withHeaders(array $headers): self
    public function withToken(string $token): self
    public function accept(string $contentType): self
    public function timeout(int $seconds): self
    public function retry(int $times, int $sleep = 0): self
    public function asJson(): self
    public function asForm(): self
    public function attach(string $name, $file): self
}
Proposed Changes
Core HTTP Components
[NEW] 
Client.php
Main HTTP client using cURL for making requests. Supports all HTTP methods.

[NEW] 
Response.php
Response wrapper providing easy access to body, JSON, status, headers.

[NEW] 
PendingRequest.php
Fluent API for building requests with headers, auth, timeout, retry.

[NEW] 
Request.php
Request object containing method, URL, headers, body, options.

Exceptions
[NEW]

Exception thrown when HTTP request fails.

Usage Examples
Simple GET Request
$response = Http::get('https://api.github.com/users/github');
$data = $response->json();
POST with Data
$response = Http::post('https://api.example.com/users', [
    'name' => 'John Doe',
    'email' => 'john@example.com',
]);
With Authentication
$response = Http::withToken('your-token')
    ->get('https://api.example.com/user');
Custom Headers
$response = Http::withHeaders([
    'X-Custom-Header' => 'value',
    'Accept' => 'application/json',
])->post('https://api.example.com/data', $data);
Timeout & Retry
$response = Http::timeout(30)
    ->retry(3, 100) // 3 times, 100ms between
    ->get('https://slow-api.com/data');
File Upload
$response = Http::attach('file', $fileContent, 'document.pdf')
    ->post('https://api.example.com/upload');
Error Handling
try {
    $response = Http::get('https://api.example.com');
    
    if ($response->successful()) {
        $data = $response->json();
    }
} catch (RequestException $e) {
    // Handle error
}

$attempt = 0;
while ($attempt < $maxAttempts) {
    try {
        return $this->send($request);
    } catch (RequestException $e) {
        $attempt++;
        if ($attempt >= $maxAttempts) throw $e;
        usleep($sleepMilliseconds * 1000);
    }
}
