Le module de gestion des stocks est un outil qui vous permet de suivre vos marchandises tout au long de votre chaîne d'approvisionnement. 
Il optimise l'ensemble du processus, de la passation de commande auprès de votre fournisseur à la livraison au client, 
en cartographiant le parcours complet d'un produit. Grâce à un suivi précis des marchandises, 
les entreprises peuvent minimiser le gaspillage, analyser les tendances et prendre de meilleures décisions d'investissement.

onctionnalités du module

Gestion des produits/services : Héritant des fonctionnalités de RISE CRM, cette fonction ajoute de nombreux attributs étendus tels que le code produit, la référence, le prix d’achat, le sous-groupe, les images, le taux de marge, le prix de vente, l’entrepôt, l’étiquette, le code-barres, les variantes, les styles, le modèle, les tailles, la couleur, la garantie, la description détaillée, etc.
