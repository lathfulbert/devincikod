✅ Prompt : Système de gestion des Flash Messages (success, error, warning, info) 

Mets en place dans le Core de mon framework  un système complet de Flash Messages, géré via la session, permettant d’afficher des retours après les soumissions de formulaires ou des actions du système.
Le système doit être modulaire, propre, inspiré de Laravel/CodeIgniter/Symfony, avec une API simple.

🎯 Objectifs du système

Gestion de plusieurs types de messages :

success

error

warning

info

Stockage automatique dans la Session et suppression après affichage (flash).

API simple côté PHP :

flash()->success("Utilisateur créé avec succès.");
flash()->error("Échec de l'opération.");
flash()->warning("Attention, champ manquant.");
flash()->info("Information mise à jour.");


Alias simple également :

Flash::success("...");


Récupération côté vue :

<?= flash()->display(); ?>


Possibilité de styler automatiquement avec Bootstrap, Tailwind ou un système custom.

Extensible à d'autres types de notifications (toast, popup JS…).

Le système doit être intégré dans le Core du framework :

Core/Flash/

Core/Flash/Flash.php (classe principale)

Core/Flash/FlashServiceProvider.php

Core/Session/Session.php (si nécessaire)

Helper global : flash() → instance du gestionnaire

Ajouter une méthode pour vérifier :

if (flash()->has('error')) { ... }


Le système clean automatiquement les messages après leur affichage.
