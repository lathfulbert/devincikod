Backoffice UI - Queue & Cron Management
Goal
Créer une interface web d'administration complète pour gérer les systèmes Queue et Cron, permettant aux administrateurs de :

Monitorer les jobs en temps réel
Gérer les jobs échoués
Voir les statistiques
Gérer les tâches cron
Visualiser les logs d'exécution

1. Queue Management Dashboard
URL: /admin/queue

Features:

📊 Vue d'ensemble (jobs actifs, échoués, rate de succès)

📈 Graphiques (Chart.js)

	Database Schema Updates
	Nouvelle table: queue_settings
	CREATE TABLE queue_settings (
		id INT PRIMARY KEY AUTO_INCREMENT,
		queue_name VARCHAR(255) NOT NULL,
		enabled BOOLEAN DEFAULT 1,
		max_workers INT DEFAULT 1,
		priority INT DEFAULT 0,
		created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
		updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
	);
	Nouvelle table: cron_task_settings
	CREATE TABLE cron_task_settings (
		id INT PRIMARY KEY AUTO_INCREMENT,
		task_class VARCHAR(255) NOT NULL UNIQUE,
		enabled BOOLEAN DEFAULT 1,
		last_run DATETIME NULL,
		next_run DATETIME NULL,
		created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
		updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
	);
