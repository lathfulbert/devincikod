Job Queue & Cron Scheduler System - Tasks
Overview
Implement a complete asynchronous job processing and scheduled task system for the framework Core, extensible by external modules.

Phase 1: Core Architecture & Contracts
	 Design interfaces and contracts
	 JobContract - Interface for all jobs
	 QueueDriverContract - Interface for queue drivers
	 CronTaskContract - Interface for cron tasks
	 QueueManager - Main orchestrator
	 CronScheduler - Cron coordinator
	 Design database schema
	 jobs table (pending jobs)
	 failed_jobs table (failures with stack traces)
	 cron_tasks table (scheduled tasks)
	 cron_logs table (execution history)
	 
Phase 2: Queue System Implementation
	 Create Queue Core structure
	 Core/Queue/ directory structure
	 QueueManager.php - Orchestrator
	 Job.php - Abstract base class
	 JobDispatcher.php - Dispatch jobs
	 JobSerializer.php - Serialize/deserialize jobs
	 Implement Queue Drivers
	 DatabaseDriver.php - Store jobs in DB
	 RedisDriver.php - Redis-based queue
	 FileDriver.php - File-based queue (dev/fallback)
	 Build Worker Process
	 QueueWorker.php - Process jobs
	 Retry logic with exponential backoff
	 Timeout handling
	 Memory management
	 Graceful shutdown (SIGTERM/SIGINT)
	 
Phase 3: Cron Scheduler Implementation
	 Create Cron Core structure
	 Core/Cron/ directory structure
	 CronScheduler.php - Main scheduler
	 CronExpression.php - Parser (cron syntax)
	 CronTask.php - Abstract base class
	 CronRunner.php - Execute tasks
	 Cron features
	 Expression parsing (*/5, 0 0 *, etc.)
	 Mutex/lock to prevent overlapping
	 Timezone support
	 Task registration from modules
	 Execution logging
	 
Phase 4: CLI Commands
	 Queue commands
	 php sunu queue:work - Start worker
	 php sunu queue:restart - Restart all workers
	 php sunu queue:retry - Retry failed jobs
	 php sunu queue:flush - Clear queue
	 php sunu queue:failed - List failed jobs
	 Cron commands
	 php sunu cron:run - Execute due tasks
	 php sunu cron:list - Show registered tasks
	 php sunu schedule:work - Daemon mode (run every minute)
	 
Phase 5: Configuration Files
	 Create config/queue.php
	 Default driver selection
	 Driver-specific config (Redis host/port, DB table, file path)
	 Worker settings (timeout, retries, sleep)
	 Failed job retention policy
	 Create config/cron.php
	 Timezone
	 Log retention
	 Overlapping prevention strategy
	 
Phase 6: Module Integration Contract
	 Define module structure
	 ModuleName/Jobs/ - Module jobs directory
	 ModuleName/Cron/ - Module cron tasks directory
	 ModuleName/queue.json - Job declarations
	 ModuleName/cron.json - Cron task declarations
	 Auto-discovery system
	 Scan modules for jobs/cron on boot
	 Register tasks in scheduler
	 Validate contracts compliance

	 Delete/flush actions
