Even with the current implementation, you can:

1. Run Migrations
php sunu migrate
This will create the 4 tables: jobs, failed_jobs, cron_tasks, cron_logs.

2. Create a Simple Job
<?php
namespace Modules\Admin\Jobs;
use App\Core\Queue\Job;
class SendEmailJob extends Job
{
    public function handle(): void
    {
        $data = $this->getData();
        echo "Sending email to: " . $data['email'] . "\n";
        
        // Email sending logic here
    }
}
3. Dispatch the Job (manual testing)
// In a controller or test script
use Modules\Admin\Jobs\SendEmailJob;
SendEmailJob::dispatch([
    'email' => 'user####example.com',
    'subject' => 'Test',
]);
echo "Job dispatched!\n";

SELECT * FROM jobs;
